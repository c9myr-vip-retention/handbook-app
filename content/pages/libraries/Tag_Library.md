# Tag Library
**Category:** Reference / Chat
**Applies to:** All VIP CS
**Version:** 2.0
**Last updated:** 26 September 2026 (current tag scheme, confirmed by ATL; replaces the 13 May 2026 Tags & Categories list)

---

## 1. How to Tag
- Tag every chat before you close it. Wrong, missing and double tags count as mistakes.
- If a chat covers several issues, tag the primary issue raised at the start.
- If a chat continues an earlier one, tag based on the earlier chat.
- When unsure, ask your Senior or ATL before tagging.
