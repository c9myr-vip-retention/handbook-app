## Procedure

| Step no. | Step name | Specific action | Operating standard | Tools / forms used | Points to note |
|---|---|---|---|---|---|
| 1 | Pull evidence per metric | At month-end after close, pull each metric from its named source. Post-close data only. | Post-close data; each metric from its source | contact_log; QA sheet; LC report; mistake log; Lark | No same-day or provisional data |
| 2 | Score each metric to a band | Map the raw to 0 / 40 / 60 / 80 / 100 by the cutoffs. A raw on a threshold takes the lower band. | Raw mapped by cutoff; threshold takes lower band | Scorecard bands | Do not round a threshold up |
| 3 | Apply the role weights | Apply the uniform weights for the role; weighted = weight x score. | Same weights for everyone in the role | Scorecard | One rubric per role; no per-person weights |
| 4 | Sum and sense-check | Sum the weighted scores; check the total matches the person real level (see band meaning). | Total = sum; squares with the band meaning | Scorecard total | A wrong-feeling total is a rubric issue, not a cell edit |
| 5 | Fix the rubric, not the cell | If the number feels wrong, adjust weights or thresholds and re-run for everyone. Never hand-lower one score. | Rubric changed uniformly; no single-cell edit | Rubric | Editing a score to a target is falsifying a record |
| 6 | Evidence-review disputes | For any disputed metric, move it only if the source evidence supports it. | Change backed by source logs | Source logs | No evidence, no change |
| 7 | Record and release | Lock the sheet, note the weights version and date; brief the agent with the coaching 5-step. | Sheet locked; version noted; agent briefed | Scorecard; Lark | Release only after sign-off |

## 1. Objective
Score each agent's monthly KPI the same way every time, from evidence, so the number reflects real performance and survives review by the SPV or Department Head.

## 2. Scope
Monthly KPI scoring for VIP RTN staff. Each person has a personalised monthly scorecard (metrics and weights set by the ATL to target their weakest areas; see KPI Framework). This SOP governs how the scorecard is set, locked and scored.

## 3. Golden Rules
- **Set and lock each scorecard before the month starts.** Metrics and weights are personalised per person, shared with them up front, and never changed after results are known. **Never edit a metric score to hit a target.** Lowering a correct score to reach a number is falsifying a record.
- **Every score is evidence-backed.** No invented figures.
- **Same metric, same cutoffs.** Weights differ per person, but a metric's band cutoffs are identical for everyone who has it, so results stay comparable.
- **A raw on a threshold takes the band it meets, not the higher one.**

## 4. Band Meaning (SPV)
| Score | Meaning |
|---|---|
| 60-65 | No mistake, baseline |
| 65-70 | Slight improvement, still needs pointer |
| 70-80 | Improving on weakness, less pointer |
| 80-90 | Above expectation, self-improving |
| 90-100 | Near perfect, exceeds the role |

## 5. Over-Scoring Guards
- No score-tuning to a target. Weights are locked before the month; changes apply from the next month only.
- Every score evidence-backed; no invented figures.
- The result must square with the band meaning in Section 4.

## 6. Remarks
- Set each person's scorecard (metrics and weights) at month start, before any results exist. Keep the previous month's version as the record.
- A shared metric's cutoff (e.g. QA) must be identical across people, or the metric is not comparable.
- New staff on probation are scored for evaluation and coaching only. Entitlement to rev share / bonus / KPI incentive is gated on passing probation (see New Staff Incentive Eligibility SOP, 37).
