## 1. Objective
Stand up a one-off or seasonal event campaign (festive, sports, payday and similar) end to end on one controlled path: proposal, approval, content, banner, bonus, issuance, tracking and teardown. So events run consistently, land on the right players, and expire cleanly.

## 2. Scope
Time-boxed events that sit outside the standing daily tasks and the permanent Weekend Campaign. This SOP owns the process. Each event's specific bonus ladder, window and creative live in that event's own proposal, not here. Excludes Weekend Campaign (its own SOP) and standing daily outreach.

## 3. Golden Rules
- **No event goes live without approval and a defined window** (hard start and end date).
- Event bonus is issued via the Bonus Issuance & Approval SOP. No new ladder bypasses the approval gate.
- **Every campaign banner has a real end date.** Never set a campaign banner to Never-Expires.
- Contact precedes deposit for any reactivation credited inside the event.
- **RG / chase flag beats the event.** Flagged players get no event message.
- State validity and turnover on every event offer.

## 4. Event Build Blocks

| Tracking | Tags, QA Record, ROI | QA Record, ROI Table SOP |
| Teardown | Expire banner, close tags, post-event review | This SOP |

## 5. Guards
- No live event without approval and a hard end date.
- Campaign banner never set to Never-Expires; it must self-drop at window end.
- No new bonus ladder outside the Bonus SOP approval gate.
- If the event overlaps the Weekend Campaign, keep the two separate. A weekday issuance of a weekend-only component is a process violation.
- RG / chase flag: no event contact.

## 6. Remarks
- **Sign-off:** every special event needs Supervisor sign-off, whatever its size (confirmed by the ATL, 26 Sep 2026).
- **Ticket query naming:** the claim ticket query uses the event name, so every event claim stays traceable (confirmed by the ATL, 26 Sep 2026).
- Reference build on file: Lucky Angbao (TC) + 30 Free Spin (Zyra), 48-hour window, RM100 deposit trigger, 114 content pieces (18 SMS, 42 IM, 54 Push). Use as the sizing benchmark for a full event set.
- No standard event calendar is locked yet (festive, sports, payday). Proposing one would let events be planned, not run reactively.
