## 1. Objective
Require every staff member to use Google Chrome in Incognito mode for all work during a shift, so no work logins, history, cookies or cache persist on the machine, and every session starts clean.

## 2. Scope
Every shift, every staff member. Covers any Chrome use for work: back office (BO), Lark and other work documents, and any website opened for a work task, on all brands. It does not change which sites you may access; it governs how Chrome is opened.

## 3. Golden Rules
- All work use of Chrome is in Incognito: back office, documents, and any browsing. No exceptions during a shift.
- Open Lark files by copying the file link and pasting it into the Incognito window, not through the Lark app or a normal browser.
- Never use a normal (non-Incognito) Chrome window for work.
- Never save or autofill work logins or passwords in Chrome.
- Non-compliance is a disciplinary matter (see Section 4).

## 4. Enforcement
| Instance | Consequence |
|---|---|
| First non-compliance | Verbal warning |
| Second non-compliance | Warning letter |
| Third non-compliance | Second warning letter |
| Fourth non-compliance | Termination |

Each stage is issued by the ATL or above, through the department disciplinary process.

## 5. Guards
- A back office or work document opened in a normal Chrome window is a violation, even once.
- Do not let Chrome save or autofill work credentials.
- If Incognito is disabled by IT or policy, report it and wait for guidance. Do not work around it in a normal window.

## 6. Remarks
- **Why:** Incognito keeps no history, cookies, cache or saved logins on the machine once the window closes, so work sessions and credentials do not persist on a shared or work device, and each shift starts with a fresh login.
- **What it does not do:** Incognito does not make activity anonymous to the company, IT or the network. The purpose is local session and credential hygiene, not hiding activity.
